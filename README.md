# БЖУ MVP

Статический трекер БЖУ для GitHub Pages.

## Файлы

- `index.html` — интерфейс
- `styles.css` — стили
- `app.js` — расчёты, локальное хранение, голосовой ввод и парсер
- `foods.json` — справочник продуктов на 100 г

## Важно

- Данные сохраняются в `localStorage` браузера. Они не синхронизируются между устройствами.
- Очистка данных сайта в браузере удалит дневник.
- Голосовой ввод использует Web Speech API и зависит от браузера.
- Значения БЖУ в `foods.json` примерные. При необходимости замените их своими проверенными значениями.
- Парсер MVP ожидает количество в граммах, например: `творог 200 грамм, банан 120 грамм`.
